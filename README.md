# Company Employee Forms Portal

A modern, responsive employee portal built using:

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

---

## Features

- Professional Dashboard
- HR Forms
- IT Forms
- Finance Forms
- Procurement Forms
- HSE Forms
- Administration Forms
- Company Policies
- Contact Directory
- Live Search
- Dark / Light Mode
- Statistics Counters
- Responsive Design
- OneDrive Integration
- Bootstrap Icons
- Scroll to Top Button

## Adding Documents

Upload your PDF, Word or Excel files to Microsoft OneDrive.

Example:

Vacation Leave Application.pdf

Expense Claim.xlsx

Medical Claim.docx

Copy the public sharing link.

Replace

YOUR_ONEDRIVE_LINK

with

https://onedrive.live.com/......

inside every Download button.
